Analytical Selection Guidelines:

  • Remove Outliers: Appropriate when observations stem from corrupt recording sensors or impossible data entry errors.
  • Retain Outliers: Recommended for NYC Taxi analysis because extreme values (e.g., JFK airport trips or long borough journeys) represent real, valid commercial transactions.
  • Winsorize Outliers: Ideal when extreme values are legitimate but would excessively skew gradient-based ML algorithms.

{% if scaling_data %}

A. Feature Scaling Fundamentals & Outlier Interactions

StandardScaler (Z-Score)

z = (x - μ) / σ

Center / Spread: Mean = 0, Std Dev = 1

Range: Unbounded (-∞, +∞)

Outlier Sensitivity: High — Outliers heavily distort the sample mean and inflate variance, compressing regular trips into an artificial cluster near zero.

MinMaxScaler (Normalization)

x' = (x - x_min) / (x_max - x_min)

Center / Spread: Bounded scale

Range: Strictly [0, 1]

Outlier Sensitivity: Severe — Extreme values establish the global min and max. For example, a $450 airport ride forces 95% of typical $15 rides into [0.0, 0.05].

RobustScaler (Median & IQR)

x' = (x - Median) / IQR

Center / Spread: Median = 0, IQR = 1

Range: Unbounded (-∞, +∞)

Outlier Sensitivity: Low / Robust — Uses the 50th percentile and interquartile range (Q3-Q1). Extreme values cannot distort the core spread, making it ideal for taxi trip data.

⚠️ Data Leakage Prevention: Training-Only Scaler Fitting

A common beginner mistake is fitting a scaler on the entire dataset before performing a train/test split. This exposes validation/test distribution parameters (μ, σ, min, max) to the model during training, causing data leakage and unrealistic performance metrics.

❌ WRONG (Data Leakage): 
scaler.fit(X_full)  # Leaks test stats!
X_train_scaled = scaler.transform(X_train)
X_test_scaled = scaler.transform(X_test)
✅ RIGHT (Strict Isolation): 
scaler.fit(X_train)  # Train stats only!
X_train_scaled = scaler.transform(X_train)
X_test_scaled = scaler.transform(X_test)
