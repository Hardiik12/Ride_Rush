Project Overview & Architecture

This web application performs end-to-end Big Data Exploratory Data Analysis (EDA) on millions of NYC Yellow Taxi trip records. Built using Dask, it demonstrates lazy task evaluation, out-of-core chunk computations, and parallel aggregations without loading the entire raw dataset into system memory at once.

Current Scope Note: This application strictly covers Exploratory Data Analysis (EDA). Feature engineering, machine learning modeling, prediction engines, and model evaluation modules will be integrated in subsequent project phases.
