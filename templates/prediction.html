Gradient Descent Mathematical Formulation

Gradient Descent iteratively updates weight $w$ and bias $b$ to minimize the Mean Squared Error (MSE) cost function $J(w, b)$:

Component Mathematical Formula Description
Hypothesis Function ŷ = w · x + b Calculates predicted fare (ŷ) for a given distance (x).
Cost Function (MSE) J(w, b) = (1 / 2m) Σ (ŷᵢ - yᵢ)² Measures average squared error between predictions and actual fares.
Weight Gradient Update w := w - α · (1 / m) Σ (ŷᵢ - yᵢ) · xᵢ Adjusts slope weight $w$ in the direction of steepest loss decrease.
Bias Gradient Update b := b - α · (1 / m) Σ (ŷᵢ - yᵢ) Adjusts intercept bias $b$ in the direction of steepest loss decrease.
